# finances-ui (MyFinances)

![MyFinances Project Image](https://github.com/JimcostDev/jimcostdev-images/blob/master/my-finances.webp?raw=true)

Es una aplicación web diseñada para la gestión integral de las finanzas personales. Está creada específicamente para simplificar el seguimiento de ingresos y gastos, ofreciendo al usuario un control completo sobre su economía. La plataforma permite generar reportes mensuales, anuales y un balance general histórico, facilitando el análisis detallado de la situación financiera a lo largo del tiempo. Además, incluye la funcionalidad de activar la opción de iglesia, destinada a registrar ofrendas especiales.
